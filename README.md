
# Dependencias 

## Instalacion full Ubuntu
```sh
apt install texlive-full latexmk biber
```

## Instalación mínima en Ubuntu
```sh
apt install \
  texlive-base \
  texlive-latex-recommended \
  texlive-latex-extra \
  texlive-lang-spanish \
  texlive-science \
  texlive-pictures \
  texlive-fonts-recommended \
  biber \
  latexmk
```

## Instalación full MacOS
```sh
brew install --cask mactex
```
